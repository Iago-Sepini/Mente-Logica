## 🚀 Sobre o Projeto

O **Mente Lógica** é um aplicativo educacional desenvolvido especialmente para introduzir jovens ao universo da **Robótica** e da **Programação com Arduino**. 

Muitas ferramentas existentes no mercado são extremamente complexas, abstratas ou pouco amigáveis para quem está dando os primeiros passos. O **Mente Lógica** surge para cobrir essa lacuna: unindo teoria descomplicada a experiências visuais e práticas imersivas, garantindo um aprendizado fluido, leve e divertido.

---

## 💡 Diferencial & Proposta de Valor

> *"Aprender a programar hardware não precisa ser assustador."*

A análise do mercado atual revela que a maioria das plataformas focadas em robótica peca pelo excesso de jargões técnicos ou interfaces poluídas. O **Mente Lógica** se destaca por:
* **Didática Acessível:** Linguagem jovem e direta ao ponto.
* **Aprenda Fazendo (Learn by Doing):** Foco imediato na aplicação prática.
* **Multimídia Integrada:** Combinação de textos, esquemas visuais, vídeos e animações para atender a diferentes estilos de aprendizagem.

---

## 🎯 Público-Alvo

* 🎒 **Estudantes do Ensino Fundamental II e Médio:** Jovens curiosos buscando desenvolver habilidades em STEM (Ciência, Tecnologia, Engenharia e Matemática).
* 🕹️ **Iniciantes e Hobbystas:** Qualquer pessoa que deseja iniciar na cultura *Maker* sem conhecimento prévio.
* 🏫 **Educadores:** Professores que buscam um recurso paradidático dinâmico para salas de aula e oficinas de robótica.

## 📚 Conteúdo Programático

O aplicativo é estruturado em módulos progressivos para garantir uma curva de aprendizado suave:
```text
 01. Introdução à Robótica & Arduino
 ├── O que é robótica?
 └── Apresentando a placa Arduino UNO
 
 02. Lógica de Programação Descomplicada
 ├── Variáveis e Estruturas Condicionais (if/else)
 └── Laços de Repetição (for/while)

 03. Componentes Eletrônicos Básicos
 ├── LEDs e Resistores (Lei de Ohm simplificada)
 └── Sensores (Luz, Temperatura e Presença)

 04. Programação Prática com Arduino
 ├── Estrutura de Código (setup e loop)
 └── Leitura e Escrita Digital/Analógica

 05. Projetos Práticos Passo a Passo
 ├── Pisca-Pisca (Blink LED)
 ├── Semáforo Inteligente
 └── Alarme com Sensor de Presença
```

## 🏁 Como Executar o Projeto

### Pré-requisitos
Antes de começar, certifique-se de ter instalado em sua máquina:
* [Git](https://git-scm.com)
* [Flutter SDK](https://docs.flutter.dev/get-started/install) (versão recente)
* Emulador Android / iOS ou um dispositivo físico configurado para depuração.

### Passos para Instalação

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/mente-logica.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd mente-logica
   ```

3. **Obtenha as dependências do Flutter:**
   ```bash
   flutter pub get
   ```

4. **Execute o aplicativo:**
   ```bash
   flutter run
   ```
